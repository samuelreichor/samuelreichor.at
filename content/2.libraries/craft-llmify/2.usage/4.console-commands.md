---
title: 'Console Commands'
description: 'Learn about the console commands available in the LLMify Craft CMS plugin.'
---

LLMify renders Markdown on demand, so none of these commands is required. They are useful in deployment pipelines or cron jobs to warm or clear the Markdown cache.

## `craft llmify/markdown/generate`

Warms the cache: caches the Markdown of every page that is enabled for LLMify and not cached yet, on all sites. Outside headless mode, pages are requested with up to [`concurrentRequests`](/libraries/craft-llmify/get-started/config#concurrentrequests) at a time. Use it after a deployment or on sites under heavy load, so no visitor has to wait for the first render of a page.

```bash
php craft llmify/markdown/generate
```

## `craft llmify/markdown/clear`

Clears the Markdown cache of all sites. Pages are rendered again on their next request.

```bash
php craft llmify/markdown/clear
```

The same is available through Craft's own command, also as **LLMify markdown** under Utilities > Clear Caches:

```bash
php craft clear-caches/llmify
```

::alert{variant="note"}
In LLMify 1.x, `generate` stored the Markdown in the database and `clear` deleted it. In 2.0 both only work on the cache.
::

## Cron Jobs

Pages drop out of the cache when they change or after [`cacheDuration`](/libraries/craft-llmify/get-started/config#cacheduration). To keep them warm, run the command regularly:

```bash
# Cache every page that is not cached yet, every night at 3am
0 3 * * * php /path/to/craft llmify/markdown/generate
```
