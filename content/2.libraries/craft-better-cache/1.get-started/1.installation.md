## Requirements

- Craft CMS 5
- PHP 8.2 or later

## Craft Plugin Store

Go to the Plugin Store in your Craft control panel, search for "Better Cache" and install it.

## Composer

::code-group

```bash [ddev]
ddev composer require samuelreichor/craft-better-cache &&
ddev craft plugin/install better-cache
```

```bash [php]
composer require samuelreichor/craft-better-cache &&
php craft plugin/install better-cache
```
::

## Setup

::steps

### Enable Caching

Better Cache is configured in `config/better-cache.php`. It is disabled by default and caches no URL until you include one:

```php [config/better-cache.php]
<?php

return [
  '*' => [
    'enabled' => true,
    'includedUriPatterns' => [
      '*' => ['.*'],
    ],
  ],
  'dev' => [
    'enabled' => false,
  ],
];
```

Visit a page as a guest and check the source. Cached pages end with `<!-- Cached by Better Cache on … -->`.

### Configure the Web Server

Without further setup, PHP serves cached pages early in the request. For the full speed, let the web server serve them directly. See [Server Configuration](/libraries/craft-better-cache/usage/server-configuration).

### Refresh After Deploys

Add `php craft better-cache/cache/invalidate` to your deploy script and run `php craft better-cache/cache/refresh-scheduled` from cron every minute. See [Commands](/libraries/craft-better-cache/usage/commands).
