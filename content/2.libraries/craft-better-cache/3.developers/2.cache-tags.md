description: 'Connect your own data to cached pages and invalidate them from code.'
---

Better Cache does not track element queries itself. It stores the cache tags Craft collects, sharpened where Craft's are too coarse (relation fields, structure queries and single-site queries), while a page renders and refreshes every page carrying a tag when Craft invalidates it. Anything that works with Craft's own caches therefore works with Better Cache.

## Custom Element Types

Element types from plugins and modules work out of the box. Their queries add cache tags like every native element query, and saving an element invalidates them through `Elements::EVENT_INVALIDATE_CACHES`.

To invalidate pages after changing data outside of an element save, use Craft's element service:

```php
// Pages showing this element
Craft::$app->getElements()->invalidateCachesForElement($element);

// Pages showing any element of this type
Craft::$app->getElements()->invalidateCachesForElementType(MyElement::class);
```

## Custom Tags

For data that is not an element, like prices from an external API, add your own tag while the page renders:

```php
Craft::$app->getElements()->collectCacheTags(['my-module:prices']);
```

When the data changes, invalidate the tag. The pages are refreshed by a queue job at the end of the request, using the [refresh strategy](/libraries/craft-better-cache/get-started/configuration#refreshstrategy):

```php
use samuelreichor\betterCache\BetterCache;

BetterCache::getInstance()->invalidation->addTags(['my-module:prices']);
```

`addTags` only matches tags exactly as they were stored. Better Cache stores the tags of element queries per site, so for element data use Craft's `invalidateCachesFor*` methods above instead. Invalidating a tag with Yii's `TagDependency::invalidate()` alone does not reach Better Cache.

## Clearing and Warming

The services behind the [commands](/libraries/craft-better-cache/usage/commands) can be called from your own code:

```php
use samuelreichor\betterCache\BetterCache;

$plugin = BetterCache::getInstance();

$plugin->invalidation->invalidateAll();                       // Apply the refresh strategy to every page
$plugin->invalidation->clearAll();                            // Delete all pages and the tag index, purge the CDN
$plugin->invalidation->clearUrl('https://example.com/blog');  // Clear a single URL
$plugin->warming->warm();                                     // Queue a render of all live and known pages
```
