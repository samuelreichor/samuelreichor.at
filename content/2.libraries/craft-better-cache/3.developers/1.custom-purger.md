---
title: 'Custom Purger'
description: 'Purge your CDN when Better Cache invalidates pages.'
---

A purger tells your CDN to drop its copies when Better Cache invalidates pages. Better Cache ships no CDN specific purger, so you write a small class for yours.

## The Interface

Implement `samuelreichor\betterCache\purgers\PurgerInterface`:

```php
interface PurgerInterface
{
    public function purgeTags(array $tags): void;

    public function purgeUrls(array $urls): void;

    public function purgeAll(): void;
}
```

::field-group
  ::field{name="purgeTags"}
  Called when pages are invalidated by tag. Receives the hashed tags, in the same form as the tag header.
  ::
  ::field{name="purgeUrls"}
  Called when a single URL is cleared, with `better-cache/cache/clear-url` or the button in the entry sidebar.
  ::
  ::field{name="purgeAll"}
  Called when the whole cache is cleared or invalidated, and when fields, sites or global sets change.
  ::
::

## Example: Cloudflare

```php [modules/CloudflarePurger.php]
<?php

namespace modules;

use Craft;
use craft\helpers\App;
use samuelreichor\betterCache\purgers\PurgerInterface;

class CloudflarePurger implements PurgerInterface
{
    public function purgeTags(array $tags): void
    {
        foreach (array_chunk($tags, 30) as $chunk) {
            $this->purge(['tags' => $chunk]);
        }
    }

    public function purgeUrls(array $urls): void
    {
        foreach (array_chunk($urls, 30) as $chunk) {
            $this->purge(['files' => $chunk]);
        }
    }

    public function purgeAll(): void
    {
        $this->purge(['purge_everything' => true]);
    }

    private function purge(array $body): void
    {
        $zoneId = App::env('CLOUDFLARE_ZONE_ID');

        Craft::createGuzzleClient()->post("https://api.cloudflare.com/client/v4/zones/$zoneId/purge_cache", [
            'headers' => ['Authorization' => 'Bearer ' . App::env('CLOUDFLARE_API_TOKEN')],
            'json' => $body,
        ]);
    }
}
```

## Register the Purger

Set the class name in your config:

```php [config/better-cache.php]
return [
  '*' => [
    'purger' => \modules\CloudflarePurger::class,
  ],
];
```

Once a purger is set, Better Cache sends `Cache-Control` and tag headers on cached pages. Errors thrown by a purger are logged and do not stop the invalidation. See [CDN](/libraries/craft-better-cache/usage/cdn) for the headers and the bypass header your CDN has to respect.
