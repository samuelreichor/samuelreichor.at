---
title: 'Switching from Blitz'
description: 'Move an existing Blitz setup to Better Cache in five steps.'
---

Wondering how the two plugins differ? [Why Better Cache](/blogs/why-better-cache) compares them under the hood.

1. Translate the config. Only `config/blitz.php` is read, not settings saved in the control panel. Settings without a Better Cache counterpart are listed as comments at the top.

    ```bash
    php craft better-cache/blitz/config > config/better-cache.php
    ```

2. Replace the template calls:

    | Blitz | Better Cache |
    |---|---|
    | `craft.blitz.includeDynamic('template', params)` | `craft.betterCache.include('template', params)` |
    | `craft.blitz.csrfInput()` | `csrfInput()` |

3. If Blitz ran on its own queue, point Better Cache to it (see [Queue](/libraries/craft-better-cache/get-started/configuration#queue)).
4. Swap the Blitz rewrite in the web server config for the [Better Cache snippet](/libraries/craft-better-cache/usage/server-configuration).
5. Uninstall Blitz, enable Better Cache and warm the cache:

    ```bash
    php craft better-cache/cache/warm
    ```
