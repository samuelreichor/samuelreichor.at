---
title: 'Dynamic Content'
description: 'Render CSRF tokens and per-visitor content on cached pages.'
---

A cached page is the same for every visitor. Personal content is filled in by a small inline script after the page loads.

## CSRF Tokens

Every `{{ csrfInput() }}` and `<meta name="csrf-token">` on a cached page gets a fresh token per visitor. No template changes are needed.

## Dynamic Includes

Render a template per visitor with `craft.betterCache.include`:

```twig
{{ craft.betterCache.include('_partials/cart', { label: 'Cart' }) }}
```

- Variables must be scalars, `null` or arrays. They travel signed in the request URL, so visitors can't change them. Pass IDs rather than large arrays.
- Included templates are rendered without the page layout, so `{% js %}` and `{% css %}` inside them are lost.

## Commerce

Saving a Commerce order (a cart) never refreshes cached pages. Anything showing the cart, like a counter in the header, must be rendered with `craft.betterCache.include`.
