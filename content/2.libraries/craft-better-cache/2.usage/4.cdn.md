## Headers

Cached pages rendered or served by PHP for guests carry:

- `Cache-Control: public, s-maxage=…, max-age=0` (setting `cdnMaxAge`)
- A tag header (setting `cacheTagHeader`, `Cache-Tag` by default, `Surrogate-Key` for Fastly)

Logged-in visitors get `Cache-Control: private, no-cache`. Stale pages and uncacheable responses get no CDN headers.

::alert{variant=note}
  The public and tag headers are only sent when a purger is configured. Pages served directly by nginx or Apache carry no PHP headers.
::

## Purger

Set `purger` to a class implementing `samuelreichor\betterCache\purgers\PurgerInterface`. It receives the hashed tags on invalidation, URLs when a single URL is cleared, and a purge of everything on clear, invalidate and changes that affect every page, like fields, sites or global sets.

See [Custom Purger](/libraries/craft-better-cache/developers/custom-purger) for a full Cloudflare example.

## Bypass Header

Re-renders and warming request the public URL. If a CDN sits in front, it must not answer requests with the `X-Better-Cache-Bypass` header from its cache. On Cloudflare, add a cache rule that bypasses the cache when the header is present.
