---
title: 'Server Configuration'
description: 'Let nginx or Apache serve cached pages without booting Craft.'
---

With the `file` storage driver, cached pages are written to `@webroot/cache/better-cache/{host}/{uri}/{query}/index.html`, where `{uri}` is the full request path, including the site's base path. The web server can serve them without booting Craft. Without the snippets below, PHP serves cached pages early in the request instead.

Only GET requests without the `X-Better-Cache-Bypass` header are served from the cache. Better Cache sends that header when it re-renders or warms pages.

::alert{variant=warning}
  With `enabled` set to `false`, Better Cache neither serves nor refreshes pages, but the web server keeps serving the stored files. Run `php craft better-cache/cache/clear` before disabling it on a server with these snippets.
::

## nginx

Replace the `try_files` line of your `location /` block:

```nginx
set $better_cache_file /better-cache-miss;
if ($request_method = GET) {
    set $better_cache_file /cache/better-cache/$host/$uri/$args/index.html;
}
if ($http_x_better_cache_bypass) {
    set $better_cache_file /better-cache-miss;
}

location / {
    try_files $better_cache_file $uri $uri/ /index.php?$query_string;
}
```

## Apache

Add these rules to `web/.htaccess`, before Craft's own rewrite rules:

```apache
RewriteEngine On
RewriteCond %{REQUEST_METHOD} GET
RewriteCond %{HTTP:X-Better-Cache-Bypass} ^$
RewriteCond %{DOCUMENT_ROOT}/cache/better-cache/%{HTTP_HOST}%{REQUEST_URI}/%{QUERY_STRING}/index.html -s
RewriteRule .* /cache/better-cache/%{HTTP_HOST}%{REQUEST_URI}/%{QUERY_STRING}/index.html [L]
```

Apache's `%{HTTP_HOST}` keeps the port and letter case the client sent, while the cache directory uses the site's lowercase host. Such requests fall through to Craft, which serves the page early in the request.

::alert{variant=note}
  If you change `cachePath`, adjust the paths above to match.
::

## Query Strings

The web server only serves a page with a query string directly when it matches the stored form exactly (params sorted, excluded ones removed). Otherwise PHP serves it early in the request.

The query string becomes a directory below the URI, so a cached `/blog/archive` is also served for `/blog?archive`.

## Verify

Cached pages end with `<!-- Cached by Better Cache on … -->`. When PHP serves a page instead of the web server, `<!-- Served by Better Cache on … -->` follows it.
